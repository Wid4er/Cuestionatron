# ¿Qué caracteriza a la orquestación de servicios?
+ Un proceso coordinador controla el orden y las condiciones de las llamadas a otros servicios
- Todos los servicios ejecutan su propia lógica sin coordinación alguna
- Únicamente se publican páginas web estáticas
- Se elimina toda comunicación de red
- Se reemplazan los mensajes por acceso directo a memoria
- Se utilizan exclusivamente llamadas de base de datos
- Solo se ejecuta un servicio sin posibilidad de invocar otros

# ¿Cómo interactúan los procesos WS-BPEL con el exterior según la especificación?
+ Importan y exportan funcionalidad mediante interfaces de servicios web
- Exigen que todos los participantes compartan memoria RAM
- Solo se comunican con sockets UDP sin contratos
- Acceden siempre directamente a las tablas de los socios
- Usan exclusivamente archivos CSV sin servicios
- No pueden recibir mensajes de clientes
- Dependen obligatoriamente de una interfaz gráfica

# ¿Qué distingue un proceso BPEL ejecutable de uno abstracto?
+ El ejecutable modela comportamiento que puede ejecutarse; el abstracto puede omitir detalles operativos
- El abstracto siempre se ejecuta más rápido que el ejecutable
- El ejecutable no admite variables y el abstracto sí
- El abstracto es un archivo WSDL de tipo binding
- El ejecutable solo contiene diagramas sin semántica
- El abstracto exige transacciones de base de datos
- No existe distinción en la especificación OASIS
