# ¿Qué es el middleware?
+ Una capa de software que facilita la comunicación entre componentes distribuidos
- Una base de datos de uso obligatorio
- Un lenguaje para diseñar páginas web
- El sistema operativo de un servidor
- Un bocadillo situado entre dos routers

# ¿Qué ventaja principal aporta el middleware?
+ Oculta parte de la complejidad de comunicar sistemas diferentes
- Elimina por completo los errores de las aplicaciones
- Hace innecesaria cualquier conexión de red
- Convierte automáticamente todos los programas en Java
- Enseña a los ordenadores a hablar por teléfono

# ¿Qué inconveniente puede introducir el middleware?
+ Latencia adicional por comunicación y procesamiento
- Garantiza siempre menor consumo de memoria
- Impide usar componentes distribuidos
- Elimina la necesidad de configurar infraestructura
- Obliga al servidor a pedir vacaciones

# ¿Qué significa interoperabilidad en un sistema distribuido?
+ Que sistemas con tecnologías distintas puedan comunicarse
- Que todos los equipos tengan el mismo procesador
- Que solo pueda utilizarse un lenguaje de programación
- Que no existan mensajes entre aplicaciones
- Que el ordenador sea amigo de la impresora

# ¿Qué caracteriza a los sistemas basados en servicios?
+ Exponen capacidades mediante contratos de servicio
- Solo permiten ejecutar aplicaciones en un ordenador
- Prohíben la comunicación por red
- Exigen compartir la memoria entre todos los clientes
- Los servicios llevan uniforme y fichan a las ocho

# ¿Qué significan las siglas SOA?
+ Service-Oriented Architecture
- Software Online Administration
- System Object Automation
- Server Optimization Algorithm
- Sociedad Oficial de Aguacates

# ¿Cuál es una idea fundamental de SOA?
+ Organizar funcionalidades como servicios con contratos bien definidos
- Hacer que todas las aplicaciones compartan su código fuente
- Prohibir la reutilización de funcionalidades
- Usar obligatoriamente un mismo sistema operativo
- Conectar las aplicaciones con cinta adhesiva

# ¿Qué es el acoplamiento débil entre servicios?
+ Depender del contrato del servicio y no de su implementación interna
- Que los servicios nunca se comuniquen
- Que todos los servicios estén en la misma máquina
- Que el consumidor modifique directamente el código del proveedor
- Que los cables Ethernet estén flojos

# ¿Qué aporta la reutilización de servicios?
+ Usar una misma funcionalidad desde distintas aplicaciones
- Crear un servicio distinto para cada usuario obligatoriamente
- Evitar cualquier intercambio de mensajes
- Eliminar las interfaces públicas
- Reciclar los servidores en el contenedor amarillo

# ¿Qué es la composición de servicios?
+ Combinar varios servicios para proporcionar una funcionalidad más amplia
- Copiar el mismo servicio veinte veces
- Convertir servicios web en archivos de imagen
- Instalar todos los servicios en un único navegador
- Formar una banda musical con microservicios

# ¿Cuál es la relación entre SOA y middleware?
+ SOA utiliza mecanismos de middleware para interactuar entre servicios
- SOA y middleware son exactamente el mismo concepto
- SOA impide utilizar middleware
- El middleware es un diagrama BPMN
- SOA es el primo lejano de HTTP

# ¿Para qué sirve WSDL?

- Para decidir qué compuerta BPMN utilizar

# En WSDL, ¿qué aporta un port?
+ Asocia un binding con una dirección de acceso al servicio
- Define únicamente el tipo de dato de una variable
- Ejecuta el código Java de los servicios
- Crea una nueva instancia de un proceso BPMN
- Es un puerto marítimo con barcos XML

# ¿Qué significa modelar un proceso de negocio?

# ¿Qué significa BPMN?
+ Business Process Model and Notation
- Basic Programming Machine Network
- Binary Process Management Node
- Business Protocol Message Number
- Bocatas, Pizza, Macarrones y Nachos

# ¿Qué diferencia a un BPMN ejecutable de uno solo descriptivo?
+ El ejecutable incorpora detalles precisos para que un motor lo ejecute
- El descriptivo siempre se escribe en Java
- El ejecutable no tiene tareas ni eventos
- El descriptivo obliga a conectarse a una aerolínea
- El ejecutable cobra un sueldo al terminar

# ¿Qué representa un evento de inicio en BPMN?
+ El comienzo de una instancia del proceso
- El final definitivo de todos los servidores
- Un error de negocio
- La llamada a cualquier servicio externo
- El momento de abrir la nevera

# ¿Qué indica un evento de fin en BPMN?
+ La finalización de un camino del proceso
- La creación de un nuevo WSDL
- La configuración del middleware
- La apertura de todas las ramas paralelas
- La jubilación del portátil

# ¿Qué representa un sequence flow en BPMN?
+ El orden de ejecución entre elementos del proceso
- La estructura XML de un mensaje SOAP
- La dirección IP del servicio
- Un tipo de contrato WSDL
- Una fila de patos programadores

# ¿Para qué sirve una compuerta exclusiva (X) en BPMN?

- Para ejecutar obligatoriamente todas las salidas
- Para almacenar los datos de la solicitud
- Para convertir HTTP en SOAP
- Para decidir quién se come la última croqueta

# ¿Qué hace una compuerta paralela al dividir el flujo?
+ Activa todas las ramas de salida
- Selecciona únicamente la rama más barata
- Detiene la ejecución para siempre
- Elimina todas las variables del proceso
- Clona físicamente el ordenador dos veces

# ¿Qué hace una compuerta paralela de unión?
+ Espera a las ramas de entrada necesarias antes de continuar
- Inicia el proceso desde cero
- Elige aleatoriamente una aerolínea
- Convierte las variables a XML
- Organiza una reunión de servidores con café

# ¿Qué es la orquestación de servicios?
+ La coordinación de varios servicios mediante un proceso central
- La comunicación sin ninguna lógica de coordinación
- La obligación de compartir una misma base de datos
- La creación de un contrato WSDL por cada variable
- Una orquesta donde los routers tocan el violín

# ¿Qué caracteriza a la coreografía de servicios?
+ Los participantes siguen reglas de interacción sin un controlador central
- Un único proceso central decide todas las llamadas
- Los participantes deben compartir su implementación interna
- Siempre hay una compuerta BPMN controlando empresas distintas
- Los microservicios se ponen a bailar flamenco

# ¿Qué diferencia fundamental existe entre orquestación y coreografía?
+ La orquestación centraliza el control; la coreografía distribuye las interacciones
- La orquestación solo usa HTTP y la coreografía solo FTP
- La coreografía necesita un único controlador y la orquestación ninguno
- La orquestación es solo una notación gráfica sin ejecución
- La primera usa batuta y la segunda castañuelas

# ¿Qué es un servicio compuesto?
+ Un servicio que ofrece una funcionalidad coordinando otros servicios
- Un servicio que funciona sin ninguna dependencia posible
- Un archivo WSDL sin operaciones
- Una base de datos que solo admite una tabla
- Un servicio construido apilando ordenadores como piezas de LEGO
